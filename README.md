# Hexadecimal to Base64 Converter

This is a simple project for converting hexadecimal to base64.

## What does this project do?

This command-line tool takes a hexadecimal number as input, verifies its validity, converts it to its binary representation, and then encodes it into Base64 format. The program guides the user through each step and provides helpful error messages for invalid input.

- **Input:** A hexadecimal number (with or without the `0x` prefix)
- **Process:**  
  1. Verifies and normalizes the input  
  2. Converts the hexadecimal to binary  
  3. Encodes the binary as Base64  
- **Output:** The Base64-encoded string

This project is a practical exercise in data encoding and string manipulation, and is useful for understanding how hexadecimal and Base64 representations work.

## Usage

1. Run the program.
2. Enter a hexadecimal number when prompted.
3. The program will output the Base64 equivalent.
